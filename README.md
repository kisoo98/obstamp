# ⏺ 타임스탬프 핫키

OBS 녹화·방송 중 핫키를 누르면 현재 시간을 자동으로 기록해주는 프로그램입니다.
나중에 영상을 돌려볼 때 원하는 장면을 찾는데 도움이 됩니다.

- **방송 중** → 방송 시간 · 실제 시각 기록 (`STREAM_*_timeline.txt`)
- **녹화 중** → 방송 시간 · 녹화 시간 · 실제 시각 기록 (`REC_*_timeline.txt`)
- **방송 + 녹화 동시** → 두 파일에 각자 형식으로 동시 기록

---

## 다운로드

[v1.0.3 릴리즈 페이지](https://github.com/kisoo98/obstamp/releases/tag/v1.0.3)에서 `timestamp_hotkey.exe` 파일을 다운받아 실행하세요.

---

## 사용 방법 (요약)

1. OBS → 도구 → **WebSocket 서버 설정**에서 활성화 (포트 `4455`)
2. `timestamp_hotkey.exe` 실행 → ⚙ 에서 연결 테스트 후 저장
3. OBS에서 녹화/방송 시작 → 프로그램 자동 활성화
4. 기록할 장면에서 **F8**
5. 녹화/방송 종료 → 타임라인 파일 자동 저장

자세한 안내는 [`docs/실행방법.txt`](docs/실행방법.txt) 참고.

---

## 타임라인 파일 예시

**방송 (`STREAM_*_timeline.txt`)**

```
# 방송 타임라인
# 기록 시작  : 2026-06-07 14:57:38
# ────────────────────────────────────────────
# [번호]  방송 시간    실제 시각
# ────────────────────────────────────────────
[001]  00:00:19.3    14:57:57
# ────────────────────────────────────────────
# 기록 종료  : 2026-06-07 15:00:30
# 총 기록    : 1개

```

**녹화 (`*_timeline.txt`)**

```
# 녹화 파일  : REC_20260607_045738
# 기록 시작  : 2026-06-07 14:57:38
# ──────────────────────────────────────────────────────
# [번호]  방송 시간    녹화 시간    실제 시각
# ──────────────────────────────────────────────────────
[001]  00:00:19.3    00:00:18.3    14:57:57
# ──────────────────────────────────────────────────────
# 기록 종료  : 2026-06-07 14:58:16
# 총 기록    : 1개
```

변경 내역은 [`변경이력.md`](변경이력.md)를 참고하세요.
