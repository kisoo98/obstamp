  타임스탬프 핫키 - 설치 및 사용법
═══════════════════════════════════════════

【 1. 설치 (최초 1회만) 】
──────────────────────────
  1) 윈도우 검색창에서 "cmd" 검색 후 실행
  2) 아래 두 줄을 각각 붙여넣고 Enter

     pip install pynput
     pip install obsws-python


【 2. OBS 설정 (최초 1회만) 】
───────────────────────────────
  1) OBS 실행
  2) 상단 메뉴 → 도구 → WebSocket 서버 설정
  3) "WebSocket 서버 활성화" 체크
  4) 포트: 4455 (기본값 그대로)
  5) 비밀번호 설정 원할 시 메모해두기
  6) 확인


【 3. 프로그램 실행 】
───────────────────────
  timestamp_hotkey.py 를 더블클릭
  (또는 cmd에서: python timestamp_hotkey.py)

  → 처음 실행 시 오른쪽 하단에 작은 창이 뜨고
    자동으로 OBS 연결을 시도합니다.

  → 연결 실패 시 ⚙ 버튼 → "OBS 연결 설정"에서
    포트/비밀번호를 입력하고 "연결 테스트 후 저장"


【 4. 사용 방법 】
──────────────────
  1) OBS에서 녹화 시작
     → 프로그램이 자동으로 활성화됩니다

  2) 기록하고 싶은 장면에서 F8 누르기
     → 현재 녹화 시간이 즉시 기록됩니다

  3) OBS에서 녹화 종료
     → 타임라인 파일이 자동으로 저장됩니다


【 저장되는 파일 】
───────────────────
  녹화 파일:    2024-01-15 14-00-00.mkv
  타임라인:     2024-01-15 14-00-00_timeline.txt

  기본적으로 녹화 파일과 같은 폴더에 저장됩니다.
  저장 위치는 ⚙ 설정에서 변경 가능합니다.

  타임라인 파일 예시:
  ─────────────────────────────────────────────
  [001]  00:03:22.1    14:03:34
  [002]  00:07:45.8    14:07:58
  [003]  00:15:01.3    14:15:13
  ─────────────────────────────────────────────
  → 영상을 볼 때 해당 시간으로 이동하면 됩니다


【 핫키 변경 】
────────────────
  ⚙ 버튼 → 핫키 칸에 입력
  예) <F9>   <scroll_lock>   <ctrl>+<F8>
